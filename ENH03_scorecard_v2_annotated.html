Change log — v1 → v2   (developer reference)
# Component Type What changed and why Implementation note
1
 Result banner + score strip Changed Both Two separate components merged into one header card (~130px → ~70px). Red circle-x icon, trainee name / scenario sub-label on left. Large % + pass/fail pill on right. Eliminates duplicate score display. Single .header-card flex row. Icon circle is 34×34px, bg #FDECEA. Score % is 21px/700. Pill is #FDECEA / #C0392B for fail, #EBF6EE / #1B5E34 for pass.
2
 Collapsed-category hint row Removed Both "4 questions — click to expand" row below each collapsed category removed. Question count moved inline as muted "N Qs" label in the category row itself. Saves one full row per collapsed category. Render .cat-qcount span inline in every .cat-row, between category name and score chip. Style: 11px, color #AAA.
3
 Category score bar Removed Both Progress bar on category rows removed. Replaced with a coloured score chip pill (green/amber/red). Bar added visual noise without adding precision over the score number. Chip is faster to scan when multiple categories are visible. Score chip: border-radius 99px, padding 2px 9px, 11px/600. Green #EBF6EE / #1B5E34 (≥60%), red #FCEBEB / #791F1F (≤25%), amber #FFF3E0 / #633806 (26–59%). Thresholds configurable.
4
 AI explanation toggle Changed Both Toggle moved from a text link on a second line below the question name to an icon-only sparkle button at the far right of the question row (after the score). Default row is now single-line. Active state: button border changes to brand orange. Button: 11px, border 1px solid #E0D5CC, color #B06020. Active: border-color: #E87B2E; color: #E87B2E. When active, chevron-up + sparkle icon. Good to have — ENH-03-03. Can be hidden if ENH-03-03 not in scope.
5
 AI explanation panel Changed Both Panel expands below the question using flex-wrap on the row container rather than a nested separate element. "Good to have" pill removed from the live UI (it was annotation-only information). Add flex-wrap: wrap to .q-row. Panel is width: 100% child, bg #FFF8F3, border-left: 2px solid #E87B2E, border-radius 0 7px 7px 0. Good to have — ENH-03-03.
6
 Export all scorecards button New Trainer only Bulk export button added to the action bar, left of the "Mark as reviewed" primary button. Brand-outline style distinguishes it from the primary action. Triggers campaign-level export: one row per question per trainee; columns: campaign, trainee, scenario, scorecard, category, question, score, AI explanation. Button: transparent bg, 1px solid #E87B2E, color #E87B2E, 12px, border-radius 7px. Export format: CSV or Excel. Good to have — ENH-03-06.
7
 Edit score button (per question) Changed Trainer only Edit button changed from labelled ("Edit") to icon-only pencil. Saves ~28px width per row. Border turns brand orange when score has been manually adjusted, providing a passive indicator without adding a separate element. Button: 11px pencil SVG icon, border 1px solid #E0E0E0, border-radius 5px, padding 2px 6px. Adjusted state: border-color: #E87B2E. Existing v3.0 capability — no score edit logic change needed (ENH-03-05).
8
 Manual adjustment indicator Changed Trainer only v1 showed adjustment on a second text line below the question name, adding a full extra row height. v2 shows an inline amber badge ("0→1") appended to the question name text. Preserves audit visibility without extra vertical space. Inline .adj-badge: bg #FFF3CD, color #856404, border #FFEAA0, 10px/500, border-radius 4px, padding 1px 6px. Display when manuallyAdjusted === true on the question object. Audit log (user ID, original, new, timestamp) handled backend — ENH-03-05.
S
 Accordion expand/collapse Same Both Category rows independently expandable. Chevron icon rotates 180° when open. Categories collapsed by default except the first. Overall score always visible (in header card, not behind accordion). ENH-03-04. Chevron: 12px SVG, stroke #AAA, CSS transform: rotate(180deg) on open state. Each category manages its own open/closed state independently.
S
 Question row hierarchy Same Both Question rows indented 28px under category rows. 5px dot marker. Lighter font weight (400) vs category name (500). Score right-aligned. Green for full marks, red for zero. ENH-03-01/02. Indentation via padding-left: 28px on .q-row. Question name: 12px/400, color #555. Category name: 13px/500, color #1A1A1A.
